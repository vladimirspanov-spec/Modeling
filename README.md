# Система автоматизации функций секретаря

Локальное приложение C++17 / Qt Widgets: календарь фирмы, моделирование, напоминания,
имитация почты, разрешение конфликтов, сохранение и статистические эксперименты.

При включённом начальном пресете календарь заранее заполнен планёрками каждого отдела
на каждый рабочий день периода и одним совещанием руководителей в неделю.
Планёрки идут параллельно в комнатах отделов; совещание — после них в конференц-зале.
Пресет можно отключить: пустой календарь заполняется вручную и событиями генератора.

Календарь поддерживает фильтр часов внутри каждого дня и просмотр будущих мероприятий.
Периодические семинары настраиваются отдельно и создаются постепенно в модельном времени.
Пользователь задаёт параметры и роль до запуска. На паузе можно добавить мероприятие,
изменить доступный по роли план и выбрать предложенный способ разрешения конфликта.
Кадровых действий в интерфейсе нет; пакетные эксперименты выполняются автоматически.

## Структура проекта

```text
src/
  main.cpp       — запуск приложения
  ui/            — окна, диалоги и анимация; пары .h / .cpp
  core/          — календарь, моделирование, сохранение и отчёты
tests/          — автоматические проверки и тестовые данные
documentation/  — руководство, описание модели и отчёт
   experiments/  — сохранённые результаты и журналы проверок
```

В корне находятся только настройки сборки и README. Рабочие исходники перечислены
в CMake, поэтому сборочные файлы не загромождают дерево проекта в Qt Creator.
`build/` и `.qtcreator/` — локальные служебные папки, исключённые из Git.
Новые пакетные эксперименты по умолчанию сохраняются в `build/experiments/results`.

```sh
cmake -S . -B build/qt6 -DQT_DIR=/usr/lib/x86_64-linux-gnu/cmake/Qt6 -DBUILD_TESTING=ON
cmake --build build/qt6 -j2
ctest --test-dir build/qt6 --output-on-failure
./build/qt6/Modeling
```

Новые прогоны: генератор `calendar-v7`, формат состояния 3. В модели оставлены
календарные события и изменения расписания. Болезни, ремонты, переводы, стресс,
навык и репутация исключены; пятичасового ограничения на новые события нет.
Состояния прежних версий v4–v6 не воспроизводятся; настройки можно загрузить отдельно.
Обновлённый LaTeX-отчёт включает диаграммы классов и объектов, спецификации, описание
интерфейса и результаты 120 прогонов v7. Исторические данные v4 сохранены отдельно.

Письма **имитируются**. Это упрощение необходимо согласовать с преподавателем.
Исходное задание предоставлено пользователем в DOCX. Правила реализации и принятые
уточнения описаны в README/MODEL; отличия от исходных требований отмечены в отчёте.
