# LaTeX-отчёт по текущему проекту

Главный файл — `report.tex`. Разделы расположены в `sections/`, векторные UML-диаграммы — в `figures/`.
Отчёт соответствует пунктам общих требований практикума: постановка задачи, диаграмма классов,
спецификации, инструменты, структура, интерфейс, эксперименты и статус GitHub. Дополнительно
включены диаграмма объектов, правила модели, проверки и ограничения реализации.

Модель — `calendar-v7`. Таблицы и выводы построены по фактически выполненным 120 прогонам
из `../experiments/results-v7/comparison.json`. Старые данные v4 в таблицы не входят.
Сведения об авторе, группе и учебном заведении на титульном листе пока не заполнены.

Из корня проекта:

```sh
python3 documentation/report/make_results.py
cd documentation/report
tectonic report.tex
```

Или дважды выполните `xelatex -interaction=nonstopmode -halt-on-error report.tex` для
оглавления и ссылок. Требуются fontspec, babel с русским языком, TikZ, booktabs, longtable,
таблицы tabularx, enumitem, listings и hyperref. Доступны запасные системные шрифты,
если DejaVu не установлен. Tectonic при первом запуске загружает пакеты и создаёт кэш.

`make_results.py` проверяет версию, число и параметры запусков, баланс заявок, средние
и выборочные стандартные отклонения. Создаёт `results_table.tex`, `results_text.tex`
и `data_manifest.json` с SHA-256 набора данных и исходников ядра. Для него достаточно Python 3.

Функции приложения при подготовке отчёта не менялись. Имитация почты и непроверенный
статус удалённого репозитория указаны явно, без заявления о полном выполнении этих пунктов.
